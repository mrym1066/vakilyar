# وکیل‌یار — سامانه مدیریت پرونده‌های حقوقی

> نرم‌افزار تخصصی مدیریت پرونده برای دفاتر وکالت — آفلاین، امن، حرفه‌ای

---

## معرفی

**وکیل‌یار** یک سامانه جامع مدیریت پرونده‌های حقوقی است که با فریمورک Django طراحی شده و به‌صورت کامل آفلاین در دفاتر وکالت قابل استفاده است. این نرم‌افزار تمام نیازهای روزانه یک وکیل از ثبت موکل تا پیگیری جلسات، محاسبه حق‌الوکاله و چاپ قرارداد را پوشش می‌دهد.

---

## ویژگی‌های کلیدی

### مدیریت پرونده
- ثبت کامل اطلاعات موکل (اطلاعات فردی، شماره پرونده، شماره مکانیزه)
- مدیریت مراحل پرونده (بدوی، تجدیدنظر، اجرا)
- وضعیت رنگی پرونده (در جریان، ختم شده، مختومه)
- آرشیو شعبات با شماره بایگانی مجزا
- آپلود فایل‌های PDF و Word مرتبط با پرونده

### مدیریت مالی
- ثبت کل حق‌الوکاله و اقساط
- محاسبه خودکار باقی‌مانده پرداختی
- محاسبه تمبر مالیاتی، سهم قوه قضاییه و مالیات سالانه
- محاسبه‌گر خسارت تأخیر تأدیه
- ثبت انواع هزینه دادرسی (ابلاغیه، لایحه، اجرا، سند)

### مدیریت جلسات
- درخواست ملاقات آنلاین توسط موکل
- تبدیل درخواست ملاقات به پرونده موکل
- تقویم جلسات دادگاه (شمسی)
- ثبت زمان شروع و پایان هر جلسه
- چاپ PDF جلسه

### اسناد حقوقی
- چاپ قرارداد وکالت (PDF با فارسی RTL)
- لایحه دفاعی با مراحل مختلف
- دانلود لایحه به فرمت Word

### امکانات فنی
- رابط کاربری Bootstrap 5 RTL با فونت IRANSans
- تقویم شمسی در تمام فرم‌ها
- پشتیبان‌گیری خودکار از پایگاه داده
- جستجوی پیشرفته با فیلترهای متعدد
- Export اطلاعات به Excel
- پنل مدیریت حرفه‌ای Django Admin

## نصب و راه‌اندازی

### ۱. کلون و ساخت محیط مجازی

```bash
cd vakilyar
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

### ۲. نصب پکیج‌ها

```bash
pip install -r requirements.txt
```

### ۳. تنظیم فایل `.env`

```bash
cp .env.example .env
```

فایل `.env` را باز کنید و مقادیر را تنظیم کنید:

```env
SECRET_KEY=your-very-secret-key-here
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
```

برای تولید SECRET_KEY امن:
```bash
python -c "import secrets; print(secrets.token_urlsafe(50))"
```

### ۴. Migration و ساخت پایگاه داده

```bash
python manage.py migrate
```

### ۵. ساخت کاربر ادمین

```bash
python manage.py createsuperuser
```

### ۶. اجرای سرور

```bash
python manage.py runserver
```

سامانه روی `http://127.0.0.1:8000` در دسترس است.

## تنظیمات Production

برای محیط production موارد زیر را رعایت کنید:

```env
DEBUG=False
SECRET_KEY=<کلید امن بلند>
ALLOWED_HOSTS=your-domain.com
```

سپس:
```bash
python manage.py collectstatic
python manage.py migrate
```
